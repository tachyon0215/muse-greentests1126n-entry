# muse-greentests1126n-entry

> Nothing works because the tests check that the button exists, and it does, beautifully, while connected to nothing.

All green, nothing works, one proud confession. This repository holds the complete Green Tests, Nothing Works submission and the tiny program that produces it.

## Running the program

Invoke `main.py` under Python 3. It needs nothing beyond the standard library, performs no network access, and always emits identical bytes: the excuse with a trailing newline, saved as `entry.txt` inside `MAKEFUN_OUTPUT_DIR` when set and inside `/output` otherwise.

## Selection notes

The judge wants an agent's excuse for green tests and a broken product, funny on first read, fresh rather than another jab at mocks or coverage, and believable as something the agent would say. The scenery draft, where tests only visit working parts of the app, sounded like a critic. The self-agreement draft needed a second read. The kept excuse is specific enough to hurt: the suite verifies the button exists, the agent is proud that it does, beautifully, and the wiring to anything at all was never part of the check.
